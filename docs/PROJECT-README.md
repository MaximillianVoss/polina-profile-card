# 01 Profile Card — React + TypeScript + Vite

## Результат

Приложение выводит две карточки профиля. Имя видно всегда, а возраст — только при `showDetails === true`: Alice показывает `Age: 20`, Ben показывает только имя.

Конкретное требование этой работы задаётся prop `showDetails`. Искусственно добавлять `useState` не нужно: значение не изменяется пользователем, поэтому локальное состояние здесь только усложнило бы решение.

## Требования к окружению

- Node.js `^20.19.4 || >=22.12.0`: подходит Node 20 начиная с 20.19.4 либо Node 22 начиная с 22.12.0 и более новые версии; Node 21 и Node 22.0–22.11 не подходят Vite 7.
- npm, установленный вместе с Node.js.

Проверьте версии:

```bash
node --version
npm --version
```

## Если работа выдана через GitHub Classroom

Примите приглашение, клонируйте созданный для вас репозиторий и откройте его корень — папку, где находятся `package.json`, `vite.config.ts` и каталог `src`.

```bash
git clone <адрес-вашего-classroom-репозитория>
cd <имя-репозитория>
npm ci
```

В Classroom-репозитории сохраняйте его готовую Vite-конфигурацию и изменяйте только файлы внутри `src`. Не создавайте `App.tsx` в корне. Не устанавливайте Expo, не импортируйте `react-native` и не используйте `StyleSheet`: это обычное веб-приложение React + TypeScript + Vite.

## `npm install` и `npm ci`

- `npm ci` читает существующий `package-lock.json`, устанавливает ровно зафиксированные версии и перед установкой пересоздаёт `node_modules`. Это основной вариант после клонирования и перед сдачей.
- `npm install` разрешает версии по диапазонам из `package.json` и может обновить `package-lock.json`. Он нужен при первом создании проекта или при осознанном добавлении зависимости.

Для готового репозитория используйте `npm ci`; не удаляйте lock-файл ради устранения ошибки.

## Запуск и проверка

```bash
npm run typecheck
npm run test:run
npm run build
npm run dev
```

`npm run dev` запускает Vite dev server, обычно по адресу `http://localhost:5173`. Остановить его можно сочетанием Control+C.

После `npm run build` можно проверить именно production-сборку:

```bash
npm exec -- vite preview
```

Vite Preview обычно доступен по адресу `http://localhost:4173`. Это не режим разработки: сначала должна существовать папка `dist`.

На macOS/Linux можно выполнить весь цикл автономным сценарием:

```bash
bash build-and-run.sh --build-only
bash build-and-run.sh --no-open
```

Первый вызов устанавливает зависимости при необходимости, проверяет типы и тесты и собирает проект. Второй после тех же проверок запускает Preview без автоматического открытия браузера.

## Основные файлы

- `src/ProfileCard.tsx` — контракт `ProfileCardProps` и условный вывод возраста.
- `src/App.tsx` — два экземпляра карточки с разными boolean-значениями.
- `src/App.css` — веб-стили через обычный CSS.
- `src/ProfileCard.test.tsx` и `src/App.test.tsx` — проверки компонента и всей страницы.
- `src/main.tsx` — подключение React к элементу `#root` из `index.html`.

Полное руководство от клонирования GitHub Classroom до проверки и сдачи, включая полное содержимое всех учебных файлов, находится в `../../../docs/tasks/01-react-profile-card.md`.

## Ручная проверка

1. Откройте `http://localhost:5173`.
2. Убедитесь, что видны две карточки и имена Alice и Ben.
3. Под Alice должна быть строка `Age: 20`.
4. Под Ben не должно быть строки возраста.
5. Сузьте окно: карточки должны перестроиться и не выходить за границы страницы.

## Частые ошибки

- `showDetails="false"` — строка, а не boolean; правильно: `showDetails={false}`.
- Корневой `App.tsx`, `app.json`, Expo и `StyleSheet` относятся к другому стеку.
- `npm run dev` проверяет разработку, а `npm exec -- vite preview` — уже собранную production-версию.
- Тесты и typecheck дополняют друг друга: тесты проверяют поведение, TypeScript — допустимые типы.
