# Исходное задание — React: Conditional rendering

## Статус

Основное задание, оцениваемое в 3 балла. В источнике оно не обозначено как Bonus или Optional.

## Что требуется

- Использовать props и state для условного отображения компонентов на основе заданных логических флагов.
- Создать React-компонент с именем `ProfileCard`.
- Компонент должен получать следующие props:
  - `name` — строка;
  - `age` — число;
  - `showDetails` — логическое значение.
- Всегда отображать значение `name`.
- Отображать значение `age` только тогда, когда `showDetails` равен `true`.
- В компоненте `App` вывести два экземпляра `ProfileCard`:
  - один с `showDetails`, равным `true`;
  - второй с `showDetails`, равным `false`.

## Ожидаемый результат

На странице отображаются две карточки профиля. Имя видно в обеих карточках, а возраст — только в карточке, для которой передан флаг `showDetails={true}`.

## Что сдавать

Формат сдачи в исходном задании не указан.

## Примечания к трактовке

- В примере результата показаны конкретные имена и значения возраста, но в тексте задания они не закреплены как обязательные данные.
- Требования к оформлению, тестам, production-сборке и структуре файлов в источнике не указаны.
- Указание на props и state приведено в общей формулировке задания; конкретное условие для `ProfileCard` описано через prop `showDetails`.
